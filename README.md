# Pioneers — تطبيق أندرويد

## الطريقة 1: بدون تثبيت أي شيء (GitHub)
1. ارفع هذا المجلد كمستودع جديد على GitHub.
2. تبويب **Actions** ← سيبني تلقائياً ← افتح آخر تشغيل ← حمّل **Pioneers-apk**.
3. انقل `app-debug.apk` للجوال وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## الطريقة 2: Android Studio
```
npm install
npx cap sync android
npx cap open android
```
ثم Build ← Build APK(s).

## تعديل الواجهة لاحقاً
عدّل `www/index.html` ثم `npx cap sync android` وأعد البناء.

## ملاحظات
- المكتبات (xlsx / exceljs) محلية داخل التطبيق، يعمل بدون إنترنت.
- تصدير Excel والنسخ الاحتياطية تفتح نافذة "مشاركة/حفظ" في أندرويد.
- الاتصال بخادم داخلي `http://192.168.x.x:5033/api` مسموح.
- البيانات محفوظة داخل التطبيق، ولمشاركتها بين الأجهزة اضبط عنوان الخادم من قسم «قاعدة البيانات».
- لتغيير الاسم/المعرّف: `capacitor.config.json`.
